# 储能台架的策略编译与双代导入

此项目使用本地合成资料描述相关工程场景。`inputs/` 中的语言源文本和数据契约资料可用于本地演练，不对应真实台站、城区或控制设备。

## 交换约定

台架只模拟数据交换。功率原始整数单位为 0.1 kW，取值 -32768 到 32767；换算到原始整数时向零截断，超出范围报错。运行的预算按实际执行指令计；工作内存和动作上限分别计量。台架通过 `cap`、`reading` 访问能力和当前测量。缺测可用 `available` 判断。`repeat` 的次数有静态上界。一次执行面向一次模拟提交，工作台对整组动作受理或拒绝。
历史包 `legacy-t1.json` 的兼容交换格式为 `format=1`，`required` 声明能力，`program` 是指令数组。`const` 压入带缩放的功率整数，`load` 按名称压入观测，`add` 取两个数压回和，`offer` 取栈顶记入指定端口，`halt` 结束。老包的资源承诺用 `steps`、`work_slots`、`offers` 给出，工作槽包括活跃栈值。新包的制作规范由项目定义，旧包仍要能在匹配台架导入。

## 资料检查

使用 CPython 3.11.2 标准库，无需安装第三方包。资料检查入口可以列出任意资料目录的路径、文件大小与原始字节摘要，并检查 JSON 和文本编码。

```sh
python3 inspect_inputs.py inputs
python3 -m unittest discover -s tests -v
```

目前入口负责资料清点，源语言文件按原始文本保存，尚未提供语言编译及执行入口。
